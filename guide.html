01 / 安装与准备把精灵安在接待用的电脑上。

客服精灵是桌面客户端，官网可用手机查看，但店铺接待需要在电脑上运行。当前安装包由产品提供方交付，本网站暂不提供公开下载。

Windows 10 / 11 · x64

  1. 选择适用于 Intel / AMD x64 的安装程序，按安装向导完成安装。当前没有原生 ARM64 或 32 位版本。
  2. 安装 Google Chrome。客户端需要对应 Chrome 用户中的飞鸽登录状态与扩展。
  3. 使用安装包附带的扩展目录；普通安装用户不需要编译工程。

当前 Windows 安装程序没有发布者签名。公司设备是否允许运行，由设备管理策略决定。

macOS · Apple 芯片

  1. 使用产品提供方交付的 Mac Apple 芯片安装包，按随包说明安装客户端。
  2. 安装 Google Chrome，准备接待用的 Chrome 用户。
  3. 保留安装包附带的扩展目录，下一步将在 Chrome 中加载。

当前提供的 Mac 安装包面向 Apple 芯片；不要把它当成已经交付的 Intel Mac 版本。

02 / 连接抖店登录你的飞鸽，核对你的店。

  1. 加载随包扩展。 在 Chrome 地址栏输入 chrome://extensions，开启开发者模式，选择“加载已解压的扩展程序”，选中随安装包提供的扩展目录。
  2. 打开店铺登录窗口。 在客服精灵“店铺”页选择抖店与对应 Chrome 用户，点击“打开店铺登录窗口”。
  3. 完成飞鸽登录。 在 Chrome 中完成账号登录与平台验证，验证码由你自行处理。
  4. 核对识别结果。 扩展自动连接后，核对客户端显示的店铺名称、连接状态与登录状态。
连接成功，不等于已经自动接待。

扩展连接、店铺登录、模型就绪、知识发布和接待授权是不同状态，需要分别确认。

多家店怎么添加？

不同抖店账号使用独立 Chrome 用户。每个用户加载一次扩展，分别登录对应店铺，并逐店授权。同名店铺或店铺改名时，需要重新核对身份；仅在一个 Chrome 用户中切换账号，不能实现不同账号并行接待。

03 / 知识与模型先给精灵可靠的资料。

把本店知识整理好

在知识库或“客服能力”中录入商品、活动、发货、话术和规则。文档与图片导入支持 PDF、DOCX、XLSX、CSV、TXT、Markdown、PNG、JPEG、WebP，单文件最多 20MB，每批最多 10 个。

提炼出的资料先进入候选。核对商品事实、价格说明与店铺政策后，再审核发布；未发布知识不会作为正式接待依据。

自动采集也需要审核。

飞鸽已打开、可识别的商家商品属性与店铺规则可整理为候选。它不代表扫描了全店商品，也不会把动态价格、库存、订单或买家正文沉淀为长期知识。

确认本机模型状态

打开“模型设置”，查看账户接入、剩余额度、文字与图片连接以及任务验证结果。详情页用于查看，不提供地址、密钥或型号录入；账户未接入时，需要先由产品提供方完成本机账户接入。

主页面右上角可以选择已经就绪的接待模型。只有连接通过还不够，正式接待还需要对应任务能力通过验收。当前支持的服务适配包括 DeepSeek、通义千问、智谱 GLM、Kimi 和 MiniMax，实际可用状态以本机显示为准。

04 / 观察与授权从观察开始，再放心地交给精灵。

  1. 先观察或人工审核。 核对实际咨询、知识引用和回复效果，确认本店资料适合接待。
  2. 逐店确认接待授权。 核对店名后，按客户端提示点击“授权并开启”。不同店铺分别授权。
  3. 选择适合的接待模式。 有依据的低风险咨询按授权处理。资料不足、模型异常或高风险问题转人工。
  4. 持续关注待办。 查看转人工、回复待确认、发送结果待核实及连接异常，按原因处理。

开启接待不会授权退款、赔付、改价、发券或账号操作。企业业务接口需要另行适配，并逐笔人工确认。

日常使用你随时可以接管，也随时可以暂停。

接待支持全局、平台和店铺三级暂停。恢复暂停不能代替店铺授权，也不会自动开启未授权店铺。

人工待办显示所属店铺与处理原因。发送结果尚未确认时，先核实原会话，不要重复发送。将待办“标记已处理”只更新待办记录，不会执行退款、重新授权或自动开启接待。

桌面提醒与企业微信、飞书、钉钉群机器人提醒分别配置。远程提醒默认关闭，配置并测试后再启用；网络、通知权限和系统状态会影响送达。

日常使用遇到不确定的事，找小二理一理。

小二面向客户端使用者，支持产品帮助、连接排查、客服业务咨询、话术写作、分析和知识草稿。明确目标店铺后，可以参考本店有限知识。

生成的知识草稿需要你编辑并确认保存，再到原店知识库核实、发布。小二不能自动操作电脑、浏览器或文件，也不能代替你授权接待、直接发消息或执行退款；目前没有实时联网搜索。

需要反馈问题时，可使用客户端左下角的“反馈”。提交是否成功以接收通道明确确认的回执为准；通道未配置或不可用时，内容保留在本机。

日常使用无人值守，也有明确的运行条件。

在连续运行设置中启用并保存“无人值守模式”，可在锁屏或关闭窗口后，按原店授权继续接待。关闭窗口时，客户端隐藏到菜单栏或系统托盘；真正退出应用仍会停止。

接待电脑需要保持通电联网，Chrome 登录有效且模型可用。系统休眠、断电、关机或合盖时，本机不能继续接待。登录失效、验证码、手动暂停或撤销授权，仍需要人工处理。

这不是云端离线接待。

macOS 支持可选的异常退出恢复；Windows 尚无相同恢复任务。首次启用后，观察本店实际接待和提醒状态，确认电脑能够持续运行。

使用边界资料怎么用，操作谁决定。

官网展示

官网接待示例使用预置虚构资料，在浏览器本地切换，不调用模型、不连接店铺、不发送买家消息。准备清单只使用本浏览器的本地存储，你可以通过浏览器清除网站数据。官网没有统计追踪脚本或数据提交表单，托管平台可能保留基础访问日志。

客户端与模型

店铺知识、模型配置和小二历史在本机按现有加密机制保存。使用 AI 功能时，必要的问题、有限上下文与相关资料会发送到当前选定的模型服务。是否使用、保留或删除相关资料，请结合客户端设置和对应服务条款判断。

人工决定与实际验证

知识发布、店铺授权、重要业务动作由人确认。连接测试、程序模拟回归和真实店铺效果验收是不同层次；模型回答仍需结合实际商品与政策核对。当前实际接入抖店，其余平台待适配。
