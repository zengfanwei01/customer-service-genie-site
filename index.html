更多使用说明
手机也能使用客服精灵吗？

官网可以在手机和平板浏览器中查看。客服精灵接待客户端目前运行于 Windows 或 macOS 电脑，手机不能代替桌面客户端执行店铺接待。

会自动处理退款、赔付吗？

不会。退款、赔付、改价等重要业务需要人工处理。遇到这些问题，精灵会提供处理线索并转入人工待办，由你核实和决定下一步。

几家店的商品知识会混在一起吗？

各店知识、授权和接待记录独立管理。多个抖店账号使用独立 Chrome 用户，分别登录与授权；店铺名称相同或改名时，需要重新核对身份。

电脑关机后，还能继续接待吗？

不能。客户端在本机运行，电脑需保持通电联网，Chrome 登录有效且模型可用。开启并保存无人值守模式后，可在锁屏或隐藏窗口时按原授权继续接待；系统休眠、断电或退出应用会停止。

店铺资料会发送到哪里？

客户端在本机保存店铺知识与配置。使用 AI 功能时，相关问题、有限上下文和必要资料会发送至当前选定的模型服务。官网演示使用预置虚构资料，不读取你的店铺或买家消息。

现在可以使用淘宝、京东和拼多多吗？

当前实际接入抖店飞鸽。淘宝 / 天猫、京东和拼多多仍待适配，不能把平台出现在目录中理解为已经可连接或接待。
